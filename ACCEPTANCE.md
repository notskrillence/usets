| Requirement | Source/software verification | External check remaining |
|---|---|---|
| Installable signed APK | Gradle build/signature; finalAPK installed and cold-launched on API30 emulator | Installation on OnePlus12R Android16 |
| Real sensor input | Android SensorManager listener; actual timestamps/rate diagnostics | Physical callbacks, rate, noise, gravity axes; nonzero Android runtime virtual-sensor test not completed |
| Gyro→mouse | PureJava integration and quantizer tests | Real Windows/iPad cursor movement |
| Primary Bluetooth HID | Real API + standard descriptor; transport tests against doubles | OxygenOS HID support, pairing, report protocol, reconnect |
| Pause/recenter/clutch/no stale movement | Resets fractions/buttons/reference; age/backlog safety; math/lifecycle tests | Physical behavior across interruptions |
| Click/drag/scroll | Button state/report tests; visible native controls | Physical host buttons, scroll and drag |
| Twelve distinct modes | Synthetic numerical signatures and mode-specific assertions | Human precision/speed/tremor tradeoffs |
| Calibration / arbitrary axes | Welford/quaternion/gravity-basis tests | Stationary physical calibration and comfortable grips |
| Presets | Strict JSON checks; real SharedPreferences implementation | Persistence/file picker on Android |
| Accuracy tests | Real local six-task implementation and control-flow metric tests | Earlier native Mouse layout checked; Lab render/touch/physical gyro user run remains |
| Recording/replay/comparison | Exact CSV roundtrip and deterministic replay tests | Export/import UI and actual-motion recording |
| Parameter tuning |20-candidate held-out OneEuro replay proxy sweep | New human trials; broad human-performance optimizer absent |
| Optional Windows UDP receiver | Compiled x64EXE; C protocol tests + Android UDP loopback doubles | Windows execution, firewall, SendInput/real cursor |
| USB/ADB / Windows precision GUI / blind randomized trials | Not implemented | Deferred research scope |

No synthetic sensor data are displayed as live hardware. Metrics are local or replay-based unless explicitly generated by the optional actual Windows receiver. No measured end-to-end hardware latency or superiority claim is made.
