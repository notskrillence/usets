# Acceptance ledger
P0: signed installable APK, live gyro angular integration, primary direct Bluetooth HID mouse for Windows and iPad, sensitivity, pause/recenter, clicks, lower-screen controls. Hardware verification must be explicit.
P1: calibration, clutch, drag/wheel, >=6 distinct modes, presets, native accuracy lab, real recording/replay/comparison, diagnostics and recovery.
P2: twelve modes, composition, replay parameter sweep, optional Windows receiver and ADB transport.
Every control must work. Sensor/report metrics must be measured. Synthetic replay never claims human performance. Preserve timestamps, fractions, report limits, and release buttons on interruption.
Delivery: APK, complete source + Gradle wrapper, companion if built, reproducible commands, honest test matrix and remaining gaps.
